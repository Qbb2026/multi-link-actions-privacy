Link Palette Privacy Policy

Effective date: August 12, 2026

This policy explains how Link Palette, published by Kalen, handles information. Support: kalen010901@gmail.com.

Summary

Link Palette is local-only. It has no account, server, analytics, telemetry, advertising, remote code, AI service, or third-party API. It does not transmit, sell, rent, or share user data.

Purpose

Link Palette performs user-initiated batch actions on links visibly selected on the current webpage.

Chrome APIs

  • activeTab — grants temporary access only after the user activates the extension on the current tab.
  • scripting — injects the packaged selector into that active tab on demand.
  • tabs — opens selected links as inactive tabs through a controlled queue.
  • bookmarks — creates a folder and bookmark entries only when requested.
  • storage — saves action presets locally.

Local processing

Visible link text and URLs are processed temporarily in the current tab to select, deduplicate, filter, copy, queue, or bookmark them. Selection data is discarded after the interaction.

Local storage

Preset names, action type, copy format, queue batch size and interval, and domain allowlist/blocklist rules. Data saved with chrome.storage.local remains in the user’s Chrome profile. Chrome may remove it when the extension is uninstalled.

Collection, transfer, and sale

Link Palette does not upload browsing data or page content, use telemetry or analytics, sell data, or transfer data to third parties. This version does not include file import or export.

Remote code

All executable code is in the installation package. No scripts, fonts, analytics, or executable configuration are loaded from the network.

Retention and deletion

Locally stored records remain until the user deletes them, clears extension storage, or uninstalls the extension.

Limited Use

Use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including Limited Use requirements. Chrome API data is used only for the prominent user-facing single purpose. It is not used for advertising, creditworthiness, lending, unrelated profiling, or transferred to humans.
